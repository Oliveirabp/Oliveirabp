### 🏭 Projetos em destaque

**[Running Control](https://github.com/Oliveirabp/Running-control-api)** — do chão de fábrica para o código

Peça esquecida na estação não é falta de atenção, é falta de sistema. Este projeto nasceu de um Kaizen real (Lean Six Sigma Green Belt) e virou um sistema completo de controle de permanência para estações de running test:

- Entrada e saída por QR code, com tempo efetivo que respeita a pausa programada
- Alertas escalonados por e-mail em 3 níveis, conforme o turno em vigor
- Modo TV para a parede da estação, indicadores com leitura executiva e Plano de ação (PDCA)
- 135 testes automatizados, PostgreSQL, Docker e CI no GitHub Actions
